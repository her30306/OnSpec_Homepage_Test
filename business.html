Battery

Machine

  • 전극공정 (코터, 롤프레스, 슬리터) 표면검사, 치수 측정 Vision
  • 조립공정 L&S라인, PKG라인 Vision
  • 모듈공정 Bur-bar 용접 Vision 외

Features

  • 2차전지 全공정 검사 Vision 시스템 개발 실적 보유
  • Multi-Channel 조명 적용으로 전극 표면 불량 및 치수 측정 정합성 향상
  • 전극공정 코터 Wet 절연부 검사 시인성 개선을 위한 조명 시스템 개발
  • Auto-Threshold 알고리즘 적용으로 우수한 코팅부 Edge 불량 검출력 향상

PCB, FPCB

Machine

  • PCB, FPCB 인쇄 회로 기판 패턴 검사기 (AOI)
  • PCB, FPCB 인쇄 회로 기판 외관 검사기 (AVI)
  • FPCB Roll to Roll 패턴 검사기 (RTR AOI & VRS)

Features

  • Global Points Transformation 방식으로, 제품의 War-page 및 수축/팽창 등의 다양한 변형에 의한 미/과검 대응
  • 자체 CAM Software로 Gerber, RS-274x, ODB++ 등 모든 Data Format 지원 및 레시피 생성 용이

Camera Module

Machine

  • Camera Module 외관검사기
  • Camera Module 6면 외관검사기
  • Laser Module 외관검사기
  • Lens 외관검사기

Features

  • Index Type 검사 Stage 구성으로 초고속 검사 구현
  • Mirror를 이용하여 Camera Module 5면 동시검사 (상면+Side 4면)
  • 액체렌즈 적용으로 제품 심도 변화 대응 및 다초점 검사 가능
  • Photometric 원리를 이용하여 외관 불량 시인성 향상
  • 10G망 적용으로 초고속 Deep-Learning 검사 결과 제공
